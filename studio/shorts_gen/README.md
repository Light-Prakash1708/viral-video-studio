Vertical (1080x1920) Shorts generator for HyperFrames. common.py = reusable Proj helpers (timeline calls, word-synced captions, counters, imgpanel, fullbleed, shake/flash/punch patterns live in the examples). audio_short.py = music + SFX (synth, real mp3s from assets/sfx, earshot bank via `bank:<id>`) + ducking + -14 LUFS, prints the voice-vs-bed gap. wt.py = Whisper word times. flo.py / mth.py = two finished examples to copy patterns from (scene layout zones, panels, counters, reaction avatar). Workflow: skills/yt-channel-studio/pipeline.md.
fp_example.py / fp_audio_example.py = network-graph explainer example (nodes, drawn edges, chips, counters, chart curves, phone feed mock, loop ending; every scene verified with snapshots + static_gaps). Reusable helpers inside: node(), badge(), chip(), edges_svg()/draw(), vpanel(), slam(), top_label(). Audio example uses earshot bank events (`bank:<id>`), music offset, key hits boosted ~2.7x so they punch through the duck.
fp2_example.py = v2 of the network explainer: named illustrated characters (face()), speech bubbles (bubble()), step-by-step demo with comparison bars, friend-list bar chart, pick-a-friend wheel, infection animation, bokeh background. Needs fp_example.py saved as /root/hf-shorts/fp.py (it reuses its helper block by exec). Voice was stretched with studio/tools/stretch_voice.py (no new TTS credits). Lesson: never reuse element ids across helpers (id collisions made a bar chart animate the background and a bubble act as a badge) - the HyperFrames check's content_overlap warnings found them.
