Reference architecture from a 4-minute animated short film (HyperFrames): build.py merges scene modules by id into index.html + sub-compositions (anchors-driven timing, HUD, captions, grain/vignette), audio_build.py places music + SFX with ducking and loudness-normalises, lib.js = reusable SVG/GSAP helpers (camera, bokeh, parallax, close-ups). Scene content is NOT included - copy the structure, write new scenes. Partial re-render + frame-accurate splice: studio/tools/splice_ranges.py.
