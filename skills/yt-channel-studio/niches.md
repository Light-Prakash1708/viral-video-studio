# Niche playbooks (pick one per channel, write the choices into its profile)
Each: hook shapes | pacing | claim/copyright risk | visual style.

**Pop-culture / games / anime commentary** - Statistic, Superlative, Teardown, Direct Address, "number four" lists. Cut every 1.5-2.5 s, reaction avatar, official art for commentary (user-approved), kinetic captions. Risk: unofficial figures (hedge), spoilers, Content ID on clips (use short fair-use cuts, own animation).
**Money / math explainers** - Statistic, Impossible Claim, Comparison. Counter-driven visuals, one big number per beat, stated assumptions on screen. Risk: "financial advice" (disclaimer), unhedged estimates, absolute claims.
**Motivation / philosophy / psychology short films** - Direct Address, Warning, Before-After. Slower (cut every 3-5 s on films), music-led, one metaphor character, loop ending. Risk: medical/therapy claims; cite studies by name.
**True crime / history** - Origin, Insider, The List. Archive footage + documents, timeline stamps, "case file" cards. Risk: defamation of living people, graphic content (age-gate), unsourced claims; primary sources only; no likeness animations of real people.
**Tech / AI tutorials** - Reveal, Receipt, Stack, Teardown. Screen capture first, result in the first 3 s. Risk: outdated versions, unverified benchmarks.
**Kids / stories** - Question, Origin. Bright palette, slower cuts, no scary hooks; check platform made-for-kids rules.
Shared: Shorts 45-70 s vertical, long 3-8 min; first 3 s must contain 2+ visual events; end on the loop line.
